# Source documents

A court opinion, an archived program, a filing, or a newspaper scan can answer a specific question about a person. Start on that person’s profile so other researchers can find what you submit. [Choose a person](../people/README.md) · [Browse all submissions](https://github.com/JakeShieldsTryingToSpell/carlson-osint/issues?q=is%3Aissue%20label%3Adocument)

## Send a document

1. Sign in to GitHub, open a profile, and select **Submit a document**. The form fills in the person’s name. Add any other people the document concerns.
2. Give it a recognizable title, such as *1991 Senate nomination of Richard W. Carlson*. Drop the PDF or scan into **Attach a document**, or paste the publisher’s URL into **Original source link**. For PDFs over 25 MB and scans over 10 MB, use the source link.
3. Name the publisher or archive, the date if known, and the page or passage to check. Select **Create**. The person’s **Browse submissions** link includes both open and closed entries.

The form is public, including files as soon as they are attached. Upload a public-shareable copy with private contact details removed. A link to the publisher works for material you cannot redistribute. [GitHub attachment guide](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)

## File it under the right person

For a file contribution, open the person’s **evidence** folder. Choose **Add file → Upload files** on your branch or fork. A contributor with a GitHub account can also use **Submit a document** and have a reviewer file it. An issue attachment reaches the public inbox immediately. The reviewer adds the source to the repository through a pull request.

1. Place a shareable original in `people/<person-id>/evidence/`. Use a descriptive filename such as `1991-senate-nomination.pdf`. For publisher-hosted material, keep the original URL.
2. Add an entry to that folder’s `README.md` with the title, issuer, date, exact page, original URL, local file link if present, and submission issue. If the source concerns multiple people, keep one copy and link to it in each person’s evidence catalog.
3. Add what the passage establishes to `research.md` and link the structured claim in the repository’s top-level `evidence/` directory. Promote a finding to the person’s short README when it helps a reader understand the family connection or a significant public event.
