# Source documents

A court opinion, an archived program, a filing, or a newspaper scan can answer a specific question about a person. Start on that person’s profile so other researchers can find what you submit. [Choose a person](../DIRECTORY.md) · [Browse all submissions](https://github.com/JakeShieldsTryingToSpell/carlson-osint/issues?q=is%3Aissue%20label%3Adocument)

## Send a document

1. Sign in to GitHub, open a profile, and select **Submit a document**. The form fills in the person’s name. Add any other people the document concerns.
2. Give it a recognizable title, such as *1991 Senate nomination of Richard W. Carlson*. Drop the PDF or scan into **Attach a document**, or paste the publisher’s URL into **Original source link**. For PDFs over 25 MB and scans over 10 MB, use the source link.
3. Name the publisher or archive, the date if known, and the page or passage to check. Select **Create**. The person’s **Browse submissions** link includes both open and closed entries.

The form is public, including files as soon as they are attached. Upload a public-shareable copy with private contact details removed. A link to the publisher works for material you cannot redistribute. [GitHub attachment guide](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/attaching-files)

## How a source enters the archive

A reviewer opens the original, checks the cited passage, and adds a citation under **Documents** on each relevant profile. The citation includes the document title, issuing body, date, page, original URL when available, and submission number. A claim based on that passage gets its own evidence record.

For a copy suitable for redistribution, put the file in `documents/<person-id>/` through a pull request. Use the profile filename without its extension as the person ID. Give the file a descriptive name, such as `1991-senate-nomination.pdf`. Store a shared document once and link to it from every relevant profile. For a source held by a publisher or archive, preserve the citation and original link on the profile.
